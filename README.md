Fly-in
=======

Python drone-routing simulator and visualizer.

Requirements
------------

- Python 3.10 or later
- `pytest` for tests
- `mypy` for type checking
- `flake8` for style checks
- `pygame` for the visualizer

Lint and type check
-------------------

```bash
flake8 .
mypy --config-file mypy.ini .
```
